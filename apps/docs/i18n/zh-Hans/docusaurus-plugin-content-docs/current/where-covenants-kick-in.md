title: 契约在哪里起作用
sidebar_position: 3
---

契约守护的是 **BTC**。买家为代币付的每一聪都进入这个代币的金库，每一次铸造和卖回都会花掉金库，并在同一笔交易里生成新的金库。只有这两种时候金库会动，而且每次都必须严格遵守代币规则：数量对应正确的价格，创建者拿到该拿的。

创建者收益和 P2P 交易都不碰金库。P2P 交易是在持有人之间转移代币，由市场负责校验，但金库里的 BTC 原地不动。

另外还有一条路径：**恢复**。如果 covs 哪天停止运营，一条带时间锁的恢复路径允许一组固定的恢复密钥转移金库。它要等很长的延迟才会开启，所以没法用它抢在正常的铸造和卖回前面。
