covs.trade 是比特币主网上的公平发射平台。每个代币总量 21,000,000，没有团队预留，并且都有自己的**契约金库**：一个没有私钥的 Taproot 地址，专门存放买家付的 BTC。其他比特币发射台把这些 BTC 放在单签国库钱包里，我们直接用脚本锁住。

BTC 一直留在金库里，所以**永远有人接盘**。任何持有人随时都能按曲线价格把代币卖回金库，换回真 BTC。创建者拿**每次铸造的 50%**，在同一笔交易里链上直接到账。打满之后，持有人之间用**预签名挂单**点对点交易：卖家只签一次名，买家成交时卖家不用在线。

一切都能自己验证。每一次发射、铸造、卖回、转账和成交都是普通的比特币交易，索引器开源且结果确定：任何人在同样的区块上跑一遍，都会得到同样的余额和同样的状态哈希。
