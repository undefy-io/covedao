title: 运作方式
sidebar_position: 2
---

**发射。** 创建者只需支付极低的发射费，代币就有了自己的金库。发射交易会记录创建者的收款地址，代币 ID 也绑定了这个地址，所以没人能复制一个发射然后把创建者的收益转走。

**铸造和卖回。** 买家按每手 1,000 枚铸造。价格分 210 个等距台阶上涨，从每手 27 sats 涨到每手 5,670 sats，整条曲线打满后金库里有 0.598 BTC。铸造时，曲线价格进金库，另外 50% 给创建者。卖回时从金库拿回曲线价格。

**交易。** 打满之后，持有人可以按自己的价格挂单。卖家预签一个挂单，保证自己刚好收到这个价；买家签名后，在一笔交易里原子结算。代币放在你钱包（Xverse、Unisat 等）里 1,000 sats 的载体输出上，covs 从不托管。
